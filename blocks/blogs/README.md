# blogs

Custom **cards** block. Purpose: article cards linking to blog posts plus a See more control.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image + title heading, date, snippet and Read article link; last row is the See more articles paragraph; heading authored as default content before the block.

## Supported variations

No variations.
